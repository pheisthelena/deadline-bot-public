# deadline-bot

Телеграм-бот, который собирает дедлайны по домашним заданиям из разных источников в один список и сообщает о новых заданиях в чат учебной группы.

Бот сделан для группы 253 программы DSBA (ФКН ВШЭ), но его можно настроить под любую группу: см. раздел [«Как сделать такого же бота для своей группы»](#как-сделать-такого-же-бота-для-своей-группы).

## Зачем он нужен

Домашки публикуются в разных местах: часть в Google Classroom, часть на wiki лектора, часть в SmartLMS, часть прямо в Telegram-чатах преподавателей. Легко что-то пропустить. Бот сам обходит все эти места и держит один актуальный список:

```
Учёба · сроки на 06.10.2026

BMGC_Group 2_26/27 — Class assignment 07 Oct: 07.10.2026 23:59 (через 1 дн.)

Economics — HA I.3: 11.10.2026 22:00 (через 5 дн.)

Calculus 2 — HW_5: 12.10.2026 23:59 (через 6 дн.)

DM2 253 26/27 — HW-5: 13.10.2026 14:41 (через 7 дн.)
```

Названия заданий в списке являются ссылками на само задание.

## Что умеет

- **Показывает список дедлайнов** по команде `/deadlines`.
- **Сам сообщает о новых дедлайнах.** Раз в 2 часа проверяет источники и пишет в чат группы, только если появилось что-то новое.
- **Собирает дедлайны из пяти источников** (подробности ниже).
- **Не дублирует задания.** Если одна и та же домашка есть в двух источниках или уже добавлена вручную, она показывается и объявляется один раз.
- **Не скрывает сданные работы.** Задание остаётся в списке до дедлайна, даже если владелец бота его уже сдал: список общий для всей группы.
- **Молчит там, где его не просили писать.** В чатах преподавателей бот только читает сообщения. Отправка в любую группу, которой нет в настройках, заблокирована на уровне кода.

## Команды

| Команда | Что делает |
|---|---|
| `/deadlines` | Показывает список предстоящих дедлайнов |
| `/add Предмет \| Задание \| 12.10 23:59` | Добавляет дедлайн вручную (время можно не писать, тогда 23:59) |
| `/del` | Показывает дедлайны, добавленные вручную и из чатов; `/del 2` удаляет второй |
| `/due 2 15.10 18:00` | Меняет срок дедлайна номер 2 из списка `/del` |
| `/help` | Показывает список команд |
| `/id` | Показывает id чата (нужен для настройки) |
| `/debug` | Служебная информация: какие курсы и события бот видит |

`/deadlines` доступна всем, в том числе в личной переписке с ботом. `/add`, `/del` и `/due` работают только в чатах, указанных в настройках.

## Откуда берутся дедлайны

| Источник | Как работает |
|---|---|
| Google Classroom | Через официальный Classroom API бот читает задания и сроки из курсов владельца (только чтение) |
| Wiki лектора (Calculus 2) | Бот разбирает таблицу Homework на странице курса и берёт столбец своей группы |
| SmartLMS | Бот скачивает личный календарь по ссылке экспорта (формат iCal) |
| Чаты преподавателей | Бот ищет в сообщениях ссылки на Яндекс Контест, по названию контеста определяет, домашка ли это, и берёт срок со страницы контеста |
| Ручной ввод | Любой участник чата группы может добавить дедлайн командой `/add` |

## Как сделать такого же бота для своей группы

Понадобятся: аккаунт Telegram, Google-аккаунт с вашими курсами Classroom, компьютер с Python 3.10+ для первой настройки и хостинг для круглосуточной работы.

### 1. Создайте бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather), отправьте `/newbot` и сохраните токен.
2. Если бот должен читать чаты преподавателей, отправьте BotFather `/setprivacy` и выберите «Disable». Сделайте это до добавления бота в чаты.

### 2. Настройте доступ к Google Classroom

1. В [Google Cloud Console](https://console.cloud.google.com) создайте проект и включите Google Classroom API. Это бесплатно, пробный период и карта не нужны.
2. В разделе «Google Auth Platform» настройте экран согласия (тип External) и добавьте себя в тестовые пользователи.
3. В разделе «Clients» создайте клиент типа «Desktop app», скачайте JSON и сохраните его рядом с ботом под именем `credentials.json`.

В режиме «Testing» вход в Google истекает через 7 дней. Чтобы этого не было, приложение нужно перевести в «In production». Для этого Google требует ссылки на домашнюю страницу, политику конфиденциальности и условия использования. Их можно бесплатно разместить на GitHub Pages (репозиторий `ваш_логин.github.io`) и указать этот адрес в «Authorized domains». Проходить проверку Google не нужно.

### 3. Заполните настройки

Скопируйте `config.example.env` под именем `config.env` и впишите токен бота и свой chat id. Свой chat id можно узнать, отправив боту `/id` после первого запуска.

### 4. Запустите бота на компьютере

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python deadline_bot.py
```

При первом запуске откроется браузер для входа в Google. После входа рядом с ботом появится файл `token.json`, и повторный вход не понадобится.

### 5. Перенесите бота на хостинг

Чтобы бот работал круглосуточно, ему нужен сервер. Подойдёт любой хостинг, который умеет запускать Python-скрипт 24/7. На сервер нужно положить `deadline_bot.py`, `requirements.txt`, `config.env`, `credentials.json` и `token.json`. Одновременно должна работать только одна копия бота.

### 6. Подключите чаты

- **Чат группы.** Добавьте бота в чат. Он пришлёт владельцу в личку id чата. Допишите этот id в `CHAT_ID` и перезапустите бота.
- **Чат преподавателя (только чтение).** Добавьте бота в чат, получите id в личку и пропишите его в `SILENT_CHATS=id:Название предмета`.

### 7. Настройте под свои предметы

Всё, что относится к конкретной группе, собрано в начале `deadline_bot.py`:

| Настройка | Что задаёт |
|---|---|
| `WIKI_URL`, `WIKI_GROUP`, `WIKI_COURSE_NAME` | Страница wiki с таблицей домашек и столбец группы |
| `SMARTLMS_COURSES` | Какие курсы из календаря SmartLMS показывать (код курса и название) |
| `CALCULUS_KEYS`, `DM_KEYS` | По каким словам узнавать курсы в Classroom |
| `DM_MAX_DAYS` | За сколько дней до срока начинать показывать домашки курса, где они опубликованы заранее на весь семестр |
| `EXCLUDE_KEYS` | Курсы Classroom, которые не нужно показывать |
| `SUBJECT_ALIASES` | Разные названия одного предмета (для поиска дубликатов) |
| `HOMEWORK_RE` | Слова, по которым контест считается домашкой |
| `CHECK_MINUTES` | Как часто проверять новые дедлайны |

Если у вас нет wiki или SmartLMS, эти источники можно не настраивать: при ошибке чтения бот показывает предупреждение, а остальные источники продолжают работать.

## Безопасность

Файлы `config.env`, `credentials.json` и `token.json` секретные: с ними посторонний человек получит доступ к боту и к вашим курсам Classroom. Никогда не выкладывайте их в открытый репозиторий, не отправляйте в чаты и не показывайте на скриншотах. Если токен бота попал в чужие руки, перевыпустите его у BotFather командой `/revoke`.

## Ограничения

- Бот видит только те курсы Classroom и SmartLMS, которые есть у владельца.
- В чатах бот читает только сообщения, отправленные после его добавления.
- Срок сдачи из свободного текста («до следующей пары») бот не понимает. Такое задание попадает в список с пометкой «срок не указан», и дату нужно задать командой `/due`.
- Автоматический сбор зависит от устройства чужих сайтов. Если страница wiki или Яндекс Контеста изменится, разбор может потребовать правки.

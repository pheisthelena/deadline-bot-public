# deadline-bot

Телеграм-бот, который собирает дедлайны по домашним заданиям из разных источников в один список и сообщает о новых заданиях в чат учебной группы.

Бот сделан для группы 253 программы DSBA (ФКН ВШЭ).

## Смысл проекта

ДЗ публикуются в разных местах: часть в Google Classroom, часть на wiki лектора, часть в SmartLMS, часть прямо в Telegram-чатах преподавателей. Бот сам обходит все эти места и держит один актуальный список, заменяя привычный ряд действий по поиску дедлайна и самого домашнего задания.
Названия заданий в списке являются ссылками на само задание.

## Функции

- **Показывает список дедлайнов** по команде `/deadlines`.
- **Сам сообщает о новых дедлайнах.** Раз в 2 часа проверяет источники и пишет в чат группы, только если появилось что-то новое.
- **Собирает дедлайны из пяти источников** (подробности ниже).
- **Не дублирует задания.** Если одна и та же домашка есть в двух источниках или уже добавлена вручную, она показывается и объявляется один раз.
- **Возможно настроить и на отправку сообщений, и на их чтение, без объявления дедлайнов в чате.** В чатах преподавателей бот только читает сообщения. Отправка в любую группу, которой нет в настройках, заблокирована на уровне кода.

## Команды

| Команда | Описание |
|---|---|
| `/deadlines` | Показывает список предстоящих дедлайнов |
| `/add Предмет \| Задание \| 12.10 23:59` | Добавляет дедлайн вручную (время можно не писать, тогда 23:59) |
| `/del` | Показывает дедлайны, добавленные вручную и из чатов; `/del 2` удаляет второй |
| `/due 2 15.10 18:00` | Меняет срок дедлайна номер 2 из списка `/del` |
| `/help` | Показывает список команд |
| `/id` | Показывает id чата (нужен для настройки) |
| `/debug` | Служебная информация: какие курсы и события бот видит |

`/deadlines` доступна всем, в том числе в личной переписке с ботом. `/add`, `/del` и `/due` работают только в чатах, указанных в настройках.

## Откуда берутся дедлайны

| Источник | Механизм работы |
|---|---|
| Google Classroom | Через официальный Classroom API бот читает задания и сроки из курсов владельца (только чтение) |
| Wiki лектора (Calculus 2) | Бот разбирает таблицу Homework на странице курса и берёт столбец своей группы |
| SmartLMS | Бот скачивает личный календарь по ссылке экспорта (формат iCal) |
| Чаты преподавателей | Бот ищет в сообщениях ссылки на Яндекс Контест, по названию контеста определяет, домашка ли это, и берёт срок со страницы контеста |
| Ручной ввод | Администратор чата группы может добавить дедлайн командой `/add` |

## Ограничения

- Бот видит только те курсы Classroom и SmartLMS, которые есть у владельца.
- В чатах бот читает только сообщения, отправленные после его добавления.
- Срок сдачи из свободного текста («до следующей пары») бот не понимает. Такое задание попадает в список с пометкой «срок не указан», и дату нужно задать командой `/due`.
- Автоматический сбор зависит от устройства чужих сайтов. Если страница wiki или Яндекс Контеста изменится, разбор может потребовать правки.
